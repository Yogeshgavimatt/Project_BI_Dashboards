# Data Jobs Dashboard w/ Power BI 

## Introduction

This is a Data Jobs Dashboard created using 2024 job postings collected from multiple job platforms.The dashboard is designed to assist **Job Seekers, Job Transitioners, and Job Swappers** in understanding the data job market — including roles, salary patterns, and job trends — all in one unified interface.Through this project, I explored and learned key *Power BI features, tools, and visualization techniques, translating real job data into an interactive, insight-driven dashboard*.

### Dashboard File
You can find the file for the dashboard here: [`Data_jobs_dashboard.pbix`](Data_jobs_dashboard.pbix).  

## Skills Showcased

My Power BI Learning Journey

During Luke’s Power BI course, I explored and practiced several core features that helped me understand how to turn raw data into meaningful insights:

- **⚙️ Data Transformation (ETL) with Power Query:** Learned how to clean, reshape, and prepare datasets — handling blanks, changing data types, and creating new columns for analysis.

- **🧮 Implicit Measures:** Practiced creating measures like `Median Yearly Salary` and `Job Count` to summarize key insights.

- **📊 Core Visuals:** Experimented with Column, Bar, Line, and Area Charts to compare job counts and observe patterns over time.

- **🗺️ Geospatial Analysis:** Used Map Charts to visualize how jobs are distributed across different countries.

- **🔢 KPI Indicators & Tables:** Built Cards to highlight main metrics and Tables for detailed, sortable data views.

- **🎨 Dashboard Design:** Focused on arranging visuals clearly and making the dashboard easy to read and explore.

- **🖱️ Interactive Reporting:**

   - Added Slicers to filter data by Job Title.
   - Used Buttons and Bookmarks for smooth navigation.
   - Tried Drill-Through to move from a summary view to detailed insights.

## Dashboard Overview

*This report is split into two distinct pages to provide both a high-level summary and a detailed analysis.*

### Page 1: High-Level Market View


![Data Jobs Dashboard Page 1](/media/Dashboard_image1.png)  


This dashboard serves as a control center for exploring the data job market. It highlights key KPIs such as total job count, median salary, and top job titles, providing a clear snapshot of current market trends at a glance.


### Page 2: Job Title Drill Through

![Data Jobs Dashboard Page 2](/media/Dashboard_image2.png) 

This page provides a detailed view for a selected job title. By drilling through from the main dashboard, you can explore specifics such as salary ranges, remote work statistics, leading hiring platforms, and a global distribution of job locations.

## Conclusion

This project represents a key milestone in my Power BI learning journey, where I applied the concepts from Luke’s course to build a complete, end-to-end data visualization project. The goal was to understand how Power BI can transform raw job posting data into an interactive and insightful tool for career analysis. 

Designing the dashboard was a valuable exercise in balancing functionality with clarity. I experimented with different chart types, layouts, and color schemes to make the insights both accessible and visually coherent. The inclusion of slicers, buttons, and drill-through features made the dashboard interactive, allowing users to move seamlessly from a high-level overview to detailed insights for specific roles. One of the most interesting aspects was incorporating geospatial visuals to map job distributions globally, which revealed regional hiring patterns in the data.

Beyond the technical learning, this project helped me appreciate how data visualization tools like Power BI bridge the gap between raw data and real-world decision-making. By slicing, filtering, and drilling through data, users can uncover meaningful patterns — such as salary variations, remote work opportunities, and emerging job titles — all of which can guide career and business decisions. Overall, this project was not just about mastering Power BI features, but about learning how to communicate data effectively and build something that turns information into understanding.
